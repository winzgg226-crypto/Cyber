UPLOAD:
1. Extract ZIP ini.
2. Upload SEMUA ISI folder ini ke ROOT repository GitHub.
3. Pastikan index.html langsung berada di root.
4. Pastikan folder assets langsung berada di root.
5. Aktifkan GitHub Pages melalui Settings > Pages.

LOGIN:
- Tidak ada username/password tetap di source code.
- Login adalah demo gate: username dan password cukup diisi.
- GitHub Pages bersifat static hosting, sehingga password sungguhan tidak dapat dirahasiakan di frontend.
- Untuk autentikasi sungguhan diperlukan backend/authentication service.
